# OpenSerrurerieUpdateWebSiteTemplateSquelette
Veuillez trouver ici le Template Squelette du projet Open Serrurerie Update Web Site.

Le projet principal est hébergé dans le GitHub Privé OpenSerrurerieUpdateWebSite.

Je gère l'avancement du projet de mise à jour du site Web de la société Open Serrurerie sur GitHub avec des Issues que j'ai calées sur "les étapes à suivre pour réaliser ton projet et ton cahier de spécifications techniques & fonctionnelles" prévues pour le stage de la Formation Développeur Web et Web Mobile. Ce stage avait une durée prévue d'un mois et que je poursuis en parallèle de mes recherches d'emploi depuis pour étoffer mon book de réalisations.

[#1 Planning des Tâches du projet avec issues sur GitHub](https://github.com/jose94752/OpenSerrurerieUpdateWebSiteTemplateSquelette/issues/1)

Ce que nous partageons ici, c'est un exemple d'utilisation de GitHub avec des Issues pour gérer les tâches d'un projet dans lequel nous partageons l'état d'avancement du GitHub Privé OpenSerrurerieUpdateWebSite au niveau des titres et des dates.

Bien entendu, les détails et l'accès au GitHub Privé pour le code et les documents sont la propriété Open Serrurerie. Néanmoins vu que le projet n'est pas terminé et publié sur le site Web d'Open Serrurerie, si vous désirez une démonstration de la maquette actuelle Desktop/Tablette, je pourrais vous montrer la maquette XAMP WordPress avec son thème personnalisé depuis mon pc personnel (logiciel de partage d'écran ou sur votre site avec ma machine).

Ce qui a changé ici:
Nous avons mis à jour les Issues avec les dates et état d'avancement actuel depuis le GitHub Privé OpenSerrurerieUpdateWebSite.
